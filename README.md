# Cheese

A browser-based chess app where you play against **Cheese** — a JavaScript chess engine ported from a custom C engine ([engine.c](https://github.com/M0HCTP/Engine)) — or **Stockfish 18**.

Play it live at **[m0hctp.github.io/cheese](https://m0hctp.github.io/cheese/)**

## Engines

- **Cheese** — from-scratch engine using 0x88 board representation, PeSTO tapered evaluation, negamax with alpha-beta pruning, transposition table, quiescence search, killer moves, and history heuristic
- **Stockfish 18** — full-strength engine (WASM lite single-threaded build)
- **Human** — play against a friend on the same screen

All engines run in Web Workers so the UI stays responsive during search.

## Opening Book

Both Cheese and Stockfish draw from a 5,478-position opening book generated by deep Stockfish analysis of the [Lichess opening database](https://github.com/lichess-org/chess-openings). Two versions are used based on difficulty level:

- **Levels 1–4**: beginner book (depth-5 evaluations)
- **Levels 5–10**: standard book (depth-26 evaluations)

## Controls

- **Engine** — Cheese, Stockfish 18, or Human
- **Level** (1–10) — sets the engine's search depth
- **Color** — play as White or Black
- **New Game** — start a fresh game
- **Cheese!** — take back your last move (available every 10 moves)
- **Flip** — rotate the board
- **Save/Load PGN** — export or import games with full annotations

## Game Analysis

After playing, click **Analyze** to have Stockfish evaluate every position and flag suboptimal moves. Analysis runs on a dedicated Stockfish worker, independent of the game engine.

### Classification

| Symbol | NAG | Category | Default threshold |
|--------|-----|-----------|-------------------|
| ?! | $6 | Inaccuracy | 50 cp |
| ? | $2 | Mistake | 100 cp |
| ?? | $4 | Blunder | 200 cp |

Thresholds are adjustable in the analysis panel.

### Reading the results

- Moves are color-coded in the move list: **yellow** (inaccuracy), **orange** (mistake), **red** (blunder)
- Click any move to see that position on the board
- Use arrow keys to step through moves
- Saved PGN includes standard numeric NAGs and the engine's principal variation as alternative lines
